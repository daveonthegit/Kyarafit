# Kyarafit – Product Requirements Document (PRD)

## Overview

Kyarafit is a mobile-first cosplay wardrobe and outfit planning app for cosplayers, fashion hobbyists, and content creators.

It centralizes costume organization, build tracking, visual outfit planning, restock alerts, and convention preparation.

## Problem

Cosplayers manage complex wardrobes across scattered tools (photos, notes, bookmarks, spreadsheets), leading to missed items, wasted money, and stressful event prep.

## Target Users

- Active cosplayers
- Convention attendees
- Fashion and costume content creators

## Core Features (MVP)

- Closet management with image cutouts
- Character build tracking with budgets
- Visual coord builder (layered canvas)
- Wishlist + restock alerts
- Convention planning mode
- Offline access to core data

## Success Metrics

- Users can complete a full build flow end-to-end
- Closet usable offline
- Clean, consistent image cutouts
- Convention plans created in <10 minutes

## Out of Scope

- Marketplace or checkout
- AI outfit generation
- Public social feeds
